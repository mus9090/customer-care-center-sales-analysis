# Call Centre Report 2023 📞

An interactive Excel dashboard analyzing call centre performance across agents, cities, and time periods.

## 📌 Objective

To build a dynamic Excel dashboard that tracks call centre KPIs, identifies top-performing agents, and uncovers trends in call volume, revenue, and customer satisfaction.


## 📂 Dataset

- **Source:** Tutorial dataset
- **Description:** Call centre data for 2023 covering 1,000 calls across 3 cities (Cincinnati, Cleveland, Columbus) and 5 representatives (R01–R05), including call duration, revenue, ratings, and caller demographics.

## ✨ Features

- **KPI Cards** — At-a-glance metrics for calls, revenue, duration, rating, and happy callers
- **Call Trends Chart** — Monthly call volume trend with peak identification (Sep–Oct)
- **Day of Week Breakdown** — Calls distributed across days, Wednesday highest at 38
- **Female vs Male Callers** — Stacked bar chart by city showing gender split
- **Rating Distribution** — Bar chart showing customer satisfaction spread (1–5)
- **Rep Performance** — Side-by-side bar charts comparing calls and revenue per representative
- **Revenue Breakdown Table** — City and customer-level revenue across all 5 reps with conditional formatting
- **Interactive Filtering** — Click R01–R05 buttons to filter dashboard by representative


## 🔍 Key Insights

- **R03** was the top-performing representative by both call volume (207) and revenue ($20.9k)
- Call volume peaked in **September and October**, suggesting seasonal demand patterns
- **Wednesday** had the highest call volume by day of week (38 calls)
- **Cleveland** had the highest total caller count across both genders


## 🛠️ Tools & Features Used

- Microsoft Excel
- Pivot Tables
- VLOOKUP
- Conditional Formatting
- Dynamic Charts (Line, Bar, Stacked Bar)
- Form Controls (Rep filter buttons)


## 🚀 How to Run

1. Open `CallCentreReport2023.xlsx` in Microsoft Excel
2. Use the R01–R05 filter buttons to explore rep-level performance
3. All charts update dynamically based on selection
